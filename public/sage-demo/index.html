The Data Model Relay

Overview

In this 30-minute relay, a team of 4 or more works through an end-to-end data modeling exercise. Each team member chooses a role, does that task, then passes the baton to the next team member.

What you need

Step 1: Choose your role

2:00
Leg 1

🔎 The Model Scout

Discover existing Sage data models for the same assay or concept, and flag what can be reused.

Leg 2

🌉 The Bridge Builder

Create a single data model that harmonizes the terms and concepts from those models.

Leg 3

🪄 The Vocabulary Wizard

Analyze how well the terms align with ontologies.

Leg 4

👾 The Final Boss

Register the final data model in Synapse and create a Curator task, catching any remaining issues before submission.

On your mark, get set, go!

30:00
Leg 1

🔎 The Model Scout

Steps
1
Find and group all assay templates

I'm exploring assay types in order to build a common data model. Using CoreModels Write Access, look at the Home Week Demo Fall 2026 project, Sage Core Data Models space. Find all assay-related Types (templates), including versioned or near-duplicate ones. Group them into assay families (e.g. DNA/epigenomic sequencing, RNA-seq/transcriptomics, proteomics/mass spec, imaging, metabolomics, microbiome, arrays/genotyping, immunoassay, clinical/behavioral/PK, other). Show the count per family as a table and a chart.

2
Open CoreModels

Open go.coremodels.io and log in with your sagebase.org email to follow along in the user interface.

Then open the Home Week Demo Fall 2026 project:

In the project, open Select Space, choose Sage Core Data Models, and click Select:

Pass the baton to the Bridge Builder when

Leg 2

🌉 The Bridge Builder

Steps
1
Harmonize the data models

I'm building a common data model for one assay. Using CoreModels Write Access, work in the Home Week Demo Fall 2026 project, in the Sage Core Data Models space. Find these data models: [insert names] Walk me through harmonizing them into a single new Type: 1. Compare their elements and taxonomies. Show me which ones mean the same thing, which differ, and which appear in only one model. 2. Propose one element per concept, reusing existing elements where they fit. 3. Create the new Type, named "[insert a name]", with those elements and taxonomies. Don't edit, move or delete the original models. In the end, I need a single schema that I will call the data model for this assay.

Pass the baton to the Vocabulary Wizard when

Leg 3

🪄 The Vocabulary Wizard

Steps
1
Create an ontology match table

Using CoreModels Write Access, look at the Home Week Demo Fall 2026 project, Sage Core Data Models space. Find the new data model [insert name] that was just created. Create a table that shows which ontologies are matched: for each element, the matching ontology term (term ID and ontology), or "no match".

Pass the baton to the Final Boss when

Leg 4

👾 The Final Boss

Steps
1
Open the Synapse project and create a folder

Open the project’s Files page in Synapse, then create a new folder and give it a name your team will recognize.

Write down the folder’s Synapse ID.

2
Upload example files

Upload at least 1 file to your new folder. You can use these example files:

  • file1.txt
  • file2.txt
  • file3.txt
  • file4.txt
  • file5.txt
3
Register the schema in Synapse and create a curation task

Using CoreModels Write Access, look at the Home Week Demo Fall 2026 project, Sage Core Data Models space. Find the new data model [insert name] that was just created. Then walk me through these steps, using the Synapse.org connector: 1. Register the new JSON schema in Synapse. 2. Bind the schema to the folder [insert the folder's Synapse ID from Step 1]. 3. Create a new file-based curation task. If you need any details, such as the organization or schema name, ask me.

You have crossed the finish line when
