Abstract

Despite more than a decade of investment in FAIR-aligned biomedical data infrastructure, data reuse remains low, with estimates around 20%. Biomedical data managers are expected to identify metadata standards that support FAIR practices, but they face a fragmented landscape of overlapping, inconsistent, and incomplete standards. A major barrier is the lack of metadata and contextual information needed for meaningful reuse and new research insights. Capturing this context is difficult because experimental designs, collection methods, and reporting practices vary widely, making metadata preparation feel like fitting a square peg into a round hole. This heterogeneity also challenges modern AI agents, causing high token usage, context-window overflow, and unreliable cross-data mappings.

This presentation introduces a joint solution from Aramai, creator of CoreModels, and Sage Bionetworks, creator of Synapse. CoreModels' graph-based data model management and cross-model mapping capabilities complement Synapse's biomedical data management platform, which supports secure storage, sharing, collaboration, and reuse of over 91 million files totaling approximately 5 petabytes of research data.

We propose a schema-authoritative retrieval layer that unifies heterogeneous biomedical data models into a single queryable knowledge graph. The graph currently contains 176 schemas and 199,028 enums. Through a Model Context Protocol server, AI agents can query schema relationships at runtime rather than relying on token-heavy inference. A structurally grounded matching method determines whether a concept maps to an existing standard, requires extension, or should become a new concept.

We demonstrate how schema-authoritative retrieval streamlines data contribution and prepares data for downstream discovery. Benchmark results on cross-data and schema-adaptation queries show reduced token use, fewer context overflows, and improved trustworthy data reuse for the life sciences community.

About the Authors

Aramai & CoreModels

Aramai builds infrastructure for managing structured knowledge, data models, and semantic relationships, so organizations can work with information consistently across people, software, and AI systems.

CoreModels is Aramai's platform for creating, managing, and reusing schemas and data models — a shared environment for concepts, relationships, and validation rules, with API and MCP integration for software and AI systems.

Sage Bionetworks & Synapse

Sage Bionetworks is a nonprofit biomedical research organization focused on advancing open science, responsible data sharing, and collaborative research. Sage builds infrastructure, governance approaches, and data resources that help research communities make biomedical data more accessible and reusable.

Synapse.org is Sage's collaborative research platform for organizing, sharing, and analyzing biomedical data — supporting everything from individual research teams to large scientific consortia with structured metadata, controlled access, provenance, and programmatic data access.

Glossary

FAIR
Findable, Accessible, Interoperable, Reusable — the four principles that decide whether a dataset can actually be discovered and reused by someone else.
Schema
A structured definition of what a dataset's fields, types, and relationships should look like.
Metadata
The descriptive context around raw data — assay type, sample details, experimental conditions — that makes it interpretable later.
Controlled vocabulary
A fixed, agreed-upon list of allowed values for a field, so the same concept isn't recorded differently across projects.
Enum
One allowed value within a controlled vocabulary — one entry in a field's list of valid options.
Provenance
The traceable record of where a schema or dataset came from, including what it was copied or extended from.
MCP
Model Context Protocol — lets an AI agent like Claude query and act on Core Models' schema graph directly, instead of guessing from training data.
Knowledge graph
A network of connected schemas, types, and enums that can be queried for relationships, rather than searched as flat text.
Assay
A specific type of experiment or measurement — whole genome sequencing, MRI imaging — that a data model is built to describe.
Consortium
A group of research teams agreeing to collect and report data the same way, so it can be combined and compared across sites.
Parent model
An existing schema that a new, more specific model is built from, automatically inheriting its fields.
Gap analysis
Comparing what metadata a dataset already has against what a model requires, to see exactly what's still missing.
